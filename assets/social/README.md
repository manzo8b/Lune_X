# Lune_X — Immagini social per Buffer

Questa cartella ospita tre esportazioni JPEG 1080×1080 ottimizzate per post Instagram, Facebook e X. Sono **adattamenti nel linguaggio visivo del kit social approvato**, realizzati usando il marchio Lune_X e gli artwork originali presenti nel repository. Non sono le sei tavole originali del kit e non devono essere presentate come tali.

- `frattura-notturna-social-1080.jpg` — Frattura Notturna
- `in-the-dark-we-see-social-1080.jpg` — In The Dark We See
- `next-stop-torremolinos-social-1080.jpg` — Next Stop: Torremolinos

Vincoli editoriali: sfondo chiaro, grafica rosa/viola, nessun punto nei titoli, nessun annuncio «Nuova uscita» privo di data confermata, nessuna durata inventata, nessuna copertina dell'artista ospite Pier Paolo Piccioni.

Queste immagini sono grafiche statiche: eventuali pulsanti «ASCOLTA» sono elementi visivi, non player interattivi; il collegamento ascolto deve essere inserito nella caption o nel link in bio.

Origine rendering: workflow `.github/workflows/social-artworks.yml`; sorgente `.github/scripts/build-social-assets.mjs`. I JPEG sono files pubblici stabili sul sito GitHub Pages dopo il deployment.

La presenza delle immagini non equivale alla pubblicazione social. Prima di pianificare, validare caption, formato e calendario di ciascun post. Non usare mai gli account della Villa.
